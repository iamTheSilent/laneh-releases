# لانه + هوش مصنوعی (MCP)

با این، Claude (توی Claude Code یا اپ Claude) به لانهٔ تیمی‌ت وصل می‌شه: تیم و پروژه‌ها رو می‌بینه، مسیر می‌چینه، کار می‌ده، تیک می‌زنه و گزارش می‌ده. با حساب خودت وارد می‌شه و دقیقاً همون دسترسی تو رو داره.

## نصب (یه خط)

**ویندوز** (PowerShell):

```powershell
irm https://raw.githubusercontent.com/iamTheSilent/laneh-releases/main/ai/install.ps1 | iex
```

**مک / لینوکس**:

```sh
curl -fsSL https://raw.githubusercontent.com/iamTheSilent/laneh-releases/main/ai/install.sh | sh
```

بعدش اپ Claude رو کامل ببند و باز کن، و توی یه چت تازه بگو: «توی لانه وارد شو». ایمیلت رو می‌پرسه و کدی که برات میاد رو بهش می‌دی. همین.

لازمه: Python 3.10 به بالا (نصب‌کنندهٔ ویندوز اگه نباشه خودش نصبش می‌کنه).
